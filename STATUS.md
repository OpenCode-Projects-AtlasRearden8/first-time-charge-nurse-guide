# STATUS — First-Time Charge Nurse Field Manual

## What was built

An education-only manual (never medical advice) for nurses asked to take the charge role for the first time, delivered two ways:

- **Markdown source** — `docs/` (10 chapters) and `worksheets/` (6 printable sheets/cards)
- **Static HTML site** — generated by `build.py` into `site/` (18 pages), stdlib-only, offline, zero dependencies

Deliberately distinct from its siblings: `new-nurse-first-year-guide` covers surviving year one as a bedside nurse, `nurse-preceptor-toolkit-guide` covers precepting a new hire — this manual covers the *shift-lead role* itself (the whole unit instead of four rooms).

### Chapters (docs/)

1. Read this first — scope, disclaimers, sibling distinctions, ground rules (observed-style examples only, policy wins, nothing personal on personal paper)
2. Saying yes and the first day — the ask (day-shift and overnight versions), the one-minute three-question confirmation, first-hour order of operations (count → grid → huddle → walk), hands-vs-reach triage
3. Assignment fairness — fair-not-equal doctrine, four-step grid-building drill (fixed points / work-sorting / pre-named co-covers / narrated trades), float-and-agency fairness, both-sides ledger (desk work counted out loud), three-question redo test
4. Shift huddle scripts — the six-sentence five-minute huddle, watch-fors (floor shapes, never persons), 60-second micro-huddle, two-sentence end-of-shift thank-down, four failure shapes with fixes
5. Flow and bed math — two-queue model (openings vs waiters), three numbers (openings by mid-shift, weighted occupancy, waiter pressure), 10:00 mid-morning audit, discharge-wave chasing, the honest five-sentence "can you take more" answer
6. Family call scripts — two-sentence call intake, five situation scripts (routine update, missing callback, angry caller, "person in charge", vigil), callback-pad hygiene
7. When to escalate — green/amber/red triggers sorted by "who has to move", second-attempt rule, escalation sentence (count + two attempts + one ask), chain-of-command fill-in, resource-move vs clinical-move boundary, no-fault team promise
8. Weathering the storm — early sick-call sequence (rework grid before calling), surge tools, the two deciding-hours pitfalls and 2-hour audit cadence, self-protection habits
9. End-of-shift debrief — last-40-minutes timeline, charge-to-charge handoff shape (state/pressure/people + open loops), thank-down craft, four-question five-minute personal debrief with one-change rule, hard-moment protocol
10. Glossary — role/coverage, board/flow, escalation, paper/process words translated

### Worksheets (worksheets/)

- `charge-day-setup.md` — first-hour fill sheet: what I have, who backs me up, today's shape
- `assignment-grid.md` — the four-step fairness grid with the both-sides ledger receipt
- `huddle-card.md` — pocket card: 5-minute huddle, 60-second micro-huddle, thank-down, failure fixes
- `escalation-card.md` — pocket card: green/amber/red trigger table, escalation sentence, chain blanks, resource-vs-clinical boundary
- `family-call-notes.md` — mine-vs-room call ownership, promise log (placeholder labels only), situation/script table, 20-minute callback promise
- `debrief-sheet.md` — loose-ends checklist, handoff fill-in, thank-down, five-minute debrief table, hard-moment protocol

### Site generator (build.py)

- Minimal markdown renderer (headings, tables, nested lists, checkboxes, blockquotes, fenced code, inline bold/italic/code/links)
- Slate-blue "charge desk" print design (distinct palette and fonts from the serif-green sibling); print styles; strict CSP (`default-src 'none'`) on every page
- Education-only banner + "not medical advice" + LLC copyright footer on every generated page
- Prev/next navigation chains for chapters and worksheets
- Source validation (`--check-only`): disclaimer phrases AND exact banner line, titles, exact counts (10 chapters / 6 worksheets), internal link resolution
- Post-build validation: every href/src in every generated page must exist inside the site tree

## How to run

```bash
python3 build.py                           # build into site/ + validate links
python3 build.py --check-only              # validate sources only
python3 -m unittest discover -s tests -v   # run the 27-test suite
```

Then open `site/index.html` in any browser — no server, no network, no analytics. (`python3 -m http.server --directory site` works too.)

## Known gaps / honest limits

- The markdown renderer covers the constructs used by these docs (no images, footnotes, or nested tables). Unsupported syntax renders as plain paragraphs rather than erroring.
- The green/amber/red levels, second-attempt rule, and fairness drills are experience-based conventions, not research citations; the guide deliberately points to facility policy and the house supervisor for anything formal.
- All examples are observed-style composites: no facility, no rooms, no names, no patient data — lookup patterns (`MRN`/`DOB` shapes) are tested against the sources as a regression guard.
- The bed-math chapter uses one toy 30-room unit shell on purpose; readers must substitute their own unit's numbers and ratios.
- Object-name emoji (🟢🟡🔴) are used in the escalation card; an ink-only print still conveys the table text, but future print polish could swap in text labels.
- No search feature; the index is the search at this size.
- External link: dylanasdale.github.io hub appears only in README; everything else is internal or sibling-project names.
- The guide is education-only by design: it deliberately does not reproduce or summarize any clinical procedure, and never will.
